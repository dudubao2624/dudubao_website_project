Assortment fit & use

For buyers adding a color-tube ball run

Consider A01-C for a route-building assortment built around colored tubes and wooden balls. For brands and distributors, the sample review can focus on how the tube route, support tiles and accessories form the selected retail set.

  1. Build the route

    Arrange the tiles with circular openings, then review straight, curved, sloping and Y-shaped tube sections against the instructions.

  2. Follow the wooden ball

    Release a listed wooden ball along the selected route and use the bowls when reviewing the layout. Check each proposed build with the sample.

  3. Prepare the retail version

    Match the component list, color choices, manual and box artwork. Compare A01-T if a clear-tube presentation is also under consideration.

Suggested review activities are checked against the selected configuration and its instructions.
