Model selection & sourcing FAQ

How is this directory different from the set comparison page?

This directory groups model and component references by product family so you can look up a code and build a sourcing shortlist. The set comparison page focuses on 14 set options by play style. Use the model detail pages to review the listed contents before selecting a sample.

How should I choose a complete set or an expansion?

Start with the intended play direction and check the contents of one pack. For example, A03-T is a complete bell ball run with 73 pieces. A05-C is a separate expansion with 8 bells and 2 balls only; the other construction pieces shown in combined builds are excluded.

Do all piece counts mean magnetic tiles only?

No. Counts include the listed accessories for each model, and instruction manuals are listed separately. Compare the component lists rather than the total alone. Confirm the final count with the selected sample and corresponding packaging before preparing your own branded box.

What should a private-label or bulk sourcing brief include?

List the model codes, quantity per model, target market and intended packaging. Add the logo, proposed instruction languages and any changes to the pictured or listed configuration. Availability, minimum quantities, sample arrangements and project timing need confirmation for the selected version.

What test documentation is available?

We have EN 71 reports for selected samples; coverage of the current sets and target-market documentation is confirmed per project.
